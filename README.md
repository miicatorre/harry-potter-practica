# 🧙 Harry Potter — Landing Page

Proyecto personal desarrollado como parte del portfolio del Grado en DAM.

## 🛠️ Tecnologías
- React 19 + Vite 8
- GSAP 3.15 (animaciones)
- CSS personalizado con temática por casas de Hogwarts

## ✨ Características
- Landing page animada con temática de Harry Potter
- Selector de casas (Gryffindor, Slytherin, Hufflepuff, Ravenclaw)
- Animaciones de cursor y partículas con GSAP
- Diseño responsive

## 🚀 Instalación
```bash
git clone https://github.com/miicatorre/harry-potter-practica.git
cd harry-potter-practica/vite-project
npm install
npm run dev
```
